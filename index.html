A full-stack e-commerce platform built with React (frontend) and Java Spring Boot (backend) following a Microservices architecture with an API Gateway. Supports secure role-based access, OAuth2 social login, and Razorpay payment integration.

🔧 Tech Stack

  • Frontend: React.js
  • Backend: Java Spring Boot, WebFlux
  • Architecture: Microservices with API Gateway
  • Databases: MySQL, MongoDB
  • Security: Spring Security, JWT Authentication, OAuth2 (Google & Amazon)
  • Password Encryption: BCrypt
  • Payment Gateway: Razorpay
  • Email Service: Java Mail Sender

🔐 Authentication & Authorization

  • Secure login and registration using JWT
  • OAuth2 social login via Google & Amazon
  • Two-tier role-based authorization
    • USER: Browse products, place orders, and make payments
    • ADMIN: Manage products and orders
  • Passwords securely stored using BCrypt hashing

✨ Features

  • User
    • Register & login (including OAuth2)
    • Browse products
    • Purchase products via Razorpay
    • Receive email notifications
  • Admin
    • Add, update, delete products
    • View and manage orders
    • Control product availability
    • Receive email notifications

🏗 Architecture

  • Microservices architecture managed through an API Gateway
  • React frontend communicates with Spring Boot REST APIs
  • Reactive programming with Spring WebFlux
  • MySQL used for structured relational data
  • MongoDB used for flexible or document-based storage
  • Stateless authentication using JWT
